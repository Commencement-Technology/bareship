# Research behind this template

The decisions in `docs/decisions/` come from three research pages (October 2026):

- RN Template Landscape: survey of Ignite, Obytes, TheCodingMachine, create-t3-turbo, create-expo-stack, the
  community templates, and the Bluesky and Expensify apps. https://claude.ai/artifact/NEMEpSEM4GYs5C3LczhW5w
- Bare Template Blueprint: the Track A plan, every template's drawbacks and our fix, system-design concepts
  mapped to files. https://claude.ai/artifact/NKnJdPFfuUoVHUig3P7kCK
- Template Decision Sheet: the questionnaire behind ADRs 0001–0012. https://claude.ai/artifact/BUHXN7xyneAFDJS6Va3NYb

Key external references: Android app architecture guide (UDF, single source of truth, layers), Bulletproof React
project structure, Feature-Sliced Design, Expensify's philosophy docs (data flow, offline patterns), and the
weeeBox mobile system design guide.
